# 字体目录

应用需要两个字体文件，请放在本目录下（文件名必须完全一致）：

| 文件名 | 用途 | 说明 |
|---|---|---|
| `DejaVuSans.ttf` | 拼音（含声调符号 ǎ ǖ ǜ） | OFL，约 700KB |
| `LXGWWenKai-Regular.ttf` | 中文（标题栏、答案页） | 霞鹜文楷，OFL，楷体风格 |

## 获取方式

DejaVu Sans：

```bash
# Debian / Ubuntu 系统已安装时可直接复制
cp /usr/share/fonts/truetype/dejavu/DejaVuSans.ttf .

# 或下载：https://github.com/dejavu-fonts/dejavu-fonts/releases
